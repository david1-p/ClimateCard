# 경기/인천 광역버스 추가 가이드

서울로 들어오는 경기도 및 인천 광역버스를 시스템에 추가하는 방법입니다.

## 배경

기후동행카드는 **서울시 면허 버스**만 적용 대상입니다. 하지만 경기/인천에서 서울로 들어오는 광역버스도 서울 정류장에 정차하므로, 사용자 편의를 위해 이 노선들을 시스템에 추가할 수 있습니다.

**중요:** 경기/인천 광역버스는 `climate_card_eligible = false`로 설정되어야 합니다.

## 1. 노선 ID 찾기

### 방법 1: 서울 공공데이터 API에서 검색

일부 경기/인천 광역버스는 서울 정류장에 정차하기 때문에 서울시 버스 API에 포함되어 있을 수 있습니다.

```bash
# 예: 1400번 버스 검색
curl "http://ws.bus.go.kr/api/rest/busRouteInfo/getBusRouteList?serviceKey=YOUR_SERVICE_KEY&strSrch=1400"
```

### 방법 2: 경기버스정보시스템(GBIS) API 사용

경기도 버스는 GBIS API를 사용합니다:
- API 문서: https://www.gbis.go.kr/gbis2014/publicService.action

### 방법 3: 인천버스정보시스템 API 사용

인천 버스는 인천시 BIS API를 사용합니다:
- API 문서: https://bus.incheon.go.kr/bis/openApiGuide05.view

## 2. 노선 정보 수집

추가하려는 광역버스의 다음 정보를 수집하세요:

- **노선번호**: 예) 1400, 9000, M5107 등
- **노선 ID (ROUTEID)**: API에서 조회한 고유 ID
- **노선 유형 (route_type)**:
  - `1`: 공항/광역버스
  - `3`: 간선버스
  - `4`: 지선버스
  - `5`: 순환버스
  - `6`: 마을버스
- **지역 정보 (region_name)**: 인천광역시, 경기도 등

## 3. 스크립트 작성

`scripts/add_gyeonggi_incheon_buses.py` 파일을 생성하고 다음과 같이 작성하세요:

```python
#!/usr/bin/env python3
"""
경기/인천 광역버스를 DB에 추가
"""
import os
import psycopg2

# 환경 변수
DB_HOST = os.getenv('DB_HOST', 'localhost')
DB_PORT = os.getenv('DB_PORT', '5432')
DB_NAME = os.getenv('DB_NAME', 'climate_transport')
DB_USER = os.getenv('DB_USER', 'postgres')
DB_PASSWORD = os.getenv('DB_PASSWORD', '1q2w')

# 경기/인천 광역버스 목록
# 형식: (ROUTEID, 노선번호, 노선유형, 지역명)
REGIONAL_BUSES = [
    # 인천 광역버스
    ('ROUTE_ID_1400', '1400', '1', '인천광역시'),
    ('ROUTE_ID_1300', '1300', '1', '인천광역시'),

    # 경기 광역버스
    ('ROUTE_ID_9000', '9000', '1', '경기도'),
    ('ROUTE_ID_M5107', 'M5107', '1', '경기도'),

    # 추가 노선을 여기에 작성하세요
]

def main():
    print("=" * 60)
    print("경기/인천 광역버스 추가")
    print("=" * 60)

    print(f"\n📋 {len(REGIONAL_BUSES)}개 노선 추가 중...\n")

    # DB 연결
    print("📡 Connecting to database...")
    conn = psycopg2.connect(
        host=DB_HOST,
        port=DB_PORT,
        dbname=DB_NAME,
        user=DB_USER,
        password=DB_PASSWORD
    )

    try:
        inserted = 0

        with conn.cursor() as cur:
            for route_id, route_name, route_type, region_name in REGIONAL_BUSES:
                try:
                    # 기후동행카드 적용 대상이 아님 (climate_card_eligible = false)
                    cur.execute("""
                        INSERT INTO routes (route_id, route_name, route_type, climate_card_eligible, region_name)
                        VALUES (%s, %s, %s, false, %s)
                        ON CONFLICT (route_id) DO UPDATE SET
                            climate_card_eligible = false,
                            route_type = EXCLUDED.route_type,
                            region_name = EXCLUDED.region_name;
                    """, (route_id, route_name, route_type, region_name))

                    if cur.rowcount > 0:
                        print(f"   ✅ {route_name} ({region_name}) - ID: {route_id}")
                        inserted += 1

                except Exception as e:
                    print(f"   ⚠️  {route_name} error: {e}")

            conn.commit()

        print(f"\n🎉 추가 완료!")
        print(f"   ✅ 총 처리: {len(REGIONAL_BUSES)}개")
        print(f"   📊 추가/업데이트: {inserted}개")

        # 지역별 통계
        with conn.cursor() as cur:
            cur.execute("""
                SELECT region_name, COUNT(*) as count
                FROM routes
                WHERE climate_card_eligible = false
                GROUP BY region_name
                ORDER BY region_name;
            """)

            print(f"\n📊 기후동행카드 미적용 노선 (지역별):")
            for row in cur.fetchall():
                print(f"   - {row[0]}: {row[1]}개")

    finally:
        conn.close()
        print("\n✅ Database connection closed")

if __name__ == '__main__':
    main()
```

## 5. 검증

추가된 노선이 정상적으로 검색되는지 확인하세요:

```bash
# API 테스트
curl "http://localhost:8080/api/routes/search?keyword=1400"

# 프론트엔드에서 검색
# http://localhost:5175 접속 후 "1400" 검색
```

## 주의사항

1. **기후동행카드 적용 여부**: 경기/인천 버스는 반드시 `climate_card_eligible = false`로 설정
2. **노선 ID 중복**: ROUTEID가 서울시 버스와 중복되지 않도록 확인
3. **지역명 표기**: 일관성을 위해 "인천광역시", "경기도"로 통일
